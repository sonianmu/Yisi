## 新增

- **每个预设都可以有自己的快捷键**：在“设置 → 模式”中，手写预设和来自模块的预设都能在所在行直接录制快捷键。点击后按下组合键，Esc 取消，Delete 清除。按下快捷键即用该预设处理选中的文字，不改变设置中当前选中的预设。
- 模块清单中的 `shortcut` 作为默认值；在 Yisi 中修改或清除后保存在偏好设置里，不改动 Agent 写的文件。
- 与其他快捷键冲突时以橙色标出，悬停可见冲突对象。预设快捷键随数据一起导出。

## 下载与注意事项

- **Yisi.dmg**：标准安装包，拖入 Applications；未公证版本首次打开按 macOS“隐私与安全性 → 仍要打开”流程操作。
- **Yisi-Assisted.zip**：完整解压，退出 Yisi，双击 `Install Yisi.command` 并确认。脚本仅解除安装副本自身的下载隔离，保留旧版备份，不使用 sudo，不关闭 Gatekeeper/SIP。
- 两个包均支持 Apple Silicon / Intel，最低 macOS 14；系统翻译需 macOS 15+，原生 Liquid Glass 需 macOS 26+。
- 可在安装包所在目录执行 `shasum -a 256 -c SHA256SUMS.txt` 校验文件。
