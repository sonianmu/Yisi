## 新增

- **模块**：让你的 Agent 不改代码、不重新打包就能扩展 Yisi。模块是 `~/Library/Application Support/Yisi/modules/` 下的文件夹，分三种：AI 服务、预设（可绑定自己的快捷键）和翻译源。处理方式可以只用提示词、调用 HTTP 服务，或运行本地程序与 Agent；文字或图片进，文字出，弹窗始终由 Yisi 负责。升级不会触碰这个文件夹。
- **设置 → 模块**：统一查看、允许、填写密钥、试运行和移除模块；其他页面只负责选用。会把文字发往新地址或运行程序的模块需要先允许，修改后重新允许；密钥只存在钥匙串。
- 每种模块都有专属的 Agent 说明（`AGENTS.md`）。在模块页一键复制给 Agent，Agent 可用 `Yisi modules validate` 和 `Yisi modules run` 自检。
- **数据导出与导入**：在“设置 → 通用 → 数据”将模块、预设、历史、学习规则和偏好导出为一个文件，在另一台 Mac 上导入；API 密钥不会导出。
- 1.3.13 中导入的翻译源自动迁移为翻译源模块，已允许的状态和密钥一并保留。手写的“这是…，请…”预设不变，仍在“设置 → 模式”中编辑。

## 外观与交互

- 设置中的切换改为带下划线的文字标签；模块、数据与软件修复的操作统一为文字链接，按钮不再带省略号。
- 空页面在整个内容区居中。
- 关于页重新排版：名称、图标与新标语“We deserve better things.”居中，链接、版权和版本号放在页脚。
- 下拉菜单文字与同一列内容左对齐；精简设置中的说明文字。

## 下载与注意事项

- **Yisi.dmg**：标准安装包，拖入 Applications；未公证版本首次打开按 macOS“隐私与安全性 → 仍要打开”流程操作。
- **Yisi-Assisted.zip**：完整解压，退出 Yisi，双击 `Install Yisi.command` 并确认。脚本仅解除安装副本自身的下载隔离，保留旧版备份，不使用 sudo，不关闭 Gatekeeper/SIP。
- 两个包均支持 Apple Silicon / Intel，最低 macOS 14；系统翻译需 macOS 15+，原生 Liquid Glass 需 macOS 26+。
- 可在安装包所在目录执行 `shasum -a 256 -c SHA256SUMS.txt` 校验文件。
