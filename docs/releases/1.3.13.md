## 新增

- **可配置翻译源**：在“设置 → 翻译 → 其他翻译源”导入 JSON 配置，可由用户自己的 Agent 适配普通 HTTP 接口，复杂签名服务可通过本地桥接接入。不内置各家 SDK，也不附带厂商密钥。
- 其他翻译源支持普通文本翻译与本地 OCR，不使用 AI 提示词、模式或智能改进；密钥保存在 Keychain，配置变更后需重新审核发送地址。
- **双安装包**：提供标准 DMG 与带辅助安装脚本的 ZIP，同时附带 SHA256 校验文件。

## 外观与交互

- 五套完整配色：原版紫、墨蓝、玉绿、暖红、柔金；分别适配深浅模式、辅助色、选中背景、按钮文字和玻璃染色，保留已有自定义颜色。
- 统一更新提示、下载/安装进度与应用内提示的外观，更新内容隐藏滚动条，进度布局居中。
- 翻译源管理使用紧凑的向下悬浮面板，与导入按钮区域对齐；开启玻璃时使用更通透的 Apple 原生 Liquid Glass，跟随主题与染色。

## 修复

- 检查更新失败不再误报“已是最新版本”，改进版本号比较与安装包识别。
- 权限引导先登记当前运行的应用；进入权限页不自动请求授权，点击“开启”仅显示系统授权提示，不再同时打开系统设置。用户可通过系统提示或后续明确按钮进入设置。
- 保留已有有效隐私授权，不因版本更新无差别清除授权。

## 下载与注意事项

- **Yisi.dmg**：标准安装包，拖入 Applications；未公证版本首次打开按 macOS“隐私与安全性 → 仍要打开”流程操作。
- **Yisi-Assisted.zip**：完整解压，退出 Yisi，双击 `Install Yisi.command` 并确认。脚本仅解除安装副本自身的下载隔离，保留旧版备份，不使用 sudo，不关闭 Gatekeeper/SIP。
- 辅助包仍不是 Apple Developer ID 签名或公证的替代品，**不会自动授予录屏、辅助功能权限**。如果系统阻止脚本启动，可用终端 `/bin/bash` 执行该脚本，或使用标准安装包。
- 两个包均支持 Apple Silicon / Intel，最低 macOS 14；系统翻译需 macOS 15+，原生 Liquid Glass 需 macOS 26+。
- 自动更新继续使用标准 DMG。可在安装包所在目录执行 `shasum -a 256 -c SHA256SUMS.txt` 校验文件。

本版通过 94 项应用测试和 21 项脚本测试。真实第三方翻译服务需用户自行提供凭据并完成适配测试。
